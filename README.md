# WMS Microservices System
## Описание проекта

Данный проект представляет собой микросервисную систему управления складом (Warehouse Management System, WMS), предназначенную для автоматизации складских операций, управления товарными запасами и обработки заказов.

Система реализована на основе микросервисной архитектуры, что обеспечивает:

- масштабируемость
- независимое развитие сервисов
- устойчивость системы
- удобство интеграции

Основная цель разработки - повышение эффективности складских операций за счёт автоматизации обработки заказов, управления остатками товаров и взаимодействия между компонентами системы через API.

Система построена на основе микросервисной архитектуры с использованием API Gateway.

### API Gateway
API Gateway выступает единой точкой входа для клиентских запросов и выполняет:

- маршрутизацию запросов
- обработку аутентификации
- управление доступом к микросервисам

### ProductService
Сервис управления товарами.
Функции:

- добавление товара
- редактирование товара
- удаление товара
- получение информации о товарах

### OrderService
Сервис обработки заказов.
Функции:

- создание заказов
- просмотр заказов
- управление статусами заказов

### SupplierService
Сервис управления поставщиками.
Функции:

- хранение информации о поставщиках
- управление контактными данными
- связь поставщиков с товарами

### StockService
Сервис управления складскими остатками.
Функции:

- хранение информации о количестве товаров
- обновление остатков
- проверка доступности товара
